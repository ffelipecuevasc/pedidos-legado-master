# Sistema de Pedidos v2.1
Sistema de toma de pedidos para la distribuidora. Delphi 5 + BDE (Paradox).

Instalacion: copiar PEDIDOS.EXE y la carpeta DATOS a C:\Pedidos\ y crear el alias PEDIDOS en el BDE Administrator.

Usuarios: pedir clave a informatica (anexo 214).

El calculo de descuentos esta en UFrmPedidos. Los informes se sacan desde Crystal Reports.

Manual de usuario en \\SERVIDOR01\Sistemas\Pedidos\manual.doc
